## CLI

The installer downloads the latest stable release for your operating system and architecture.

<Tabs>
  <TabItem label="macOS and Linux">
    ```sh
    curl -fsSL https://nasduck.dev/install.sh | sh
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    irm https://nasduck.dev/install.ps1 | iex
    ```
  </TabItem>
</Tabs>

### Homebrew

```sh
brew tap shiplaone2q/nasduck https://github.com/shiplaone2q/nasduck
brew install nasduck
```

You can also download platform archives from [GitHub Releases](https://github.com/shiplaone2q/nasduck/releases).

### Verify the installation

```sh
nasduck --version
```

If your shell cannot find `nasduck`, restart the terminal or check that the installation directory is on your `PATH`.

## Libraries

Library sessions run in your process and do not require the CLI.

<Tabs>
  <TabItem label="Python">
    Requires Python 3.8 or newer.

    ```sh
    pip install nasduck
    ```

  </TabItem>
  <TabItem label="JavaScript">
    Requires Node.js 20 or newer.

    ```sh
    npm install @shiplaone2q/nasduck
    ```

  </TabItem>
  <TabItem label="Rust">
    Requires Rust 1.90 or newer.

    ```sh
    cargo add nasduck-rs
    ```

    [Rust API reference](https://docs.rs/nasduck-rs/latest/nasduck/)
  </TabItem>
  <TabItem label="Go">
    Requires Go 1.26 or newer. Published modules include the native engine.

    ```sh
    go get github.com/shiplaone2q/nasduck/bindings/go@latest
    ```

  </TabItem>
</Tabs>
